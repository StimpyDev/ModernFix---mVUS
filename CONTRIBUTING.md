ModernFix is a Fabric mod powered by Fabric Loom. To build the mod, run the `build` task (e.g. via `./gradlew build`).
You must use Java 21 to develop ModernFix as the toolchain requires it.
For versions above 1.21.11 Java 25 must be used.

## Submitting pull requests

Code or documentation contributions are welcome. Please keep the following points in mind:

* Please ensure your code is reasonably neat and sufficiently documented. Remember that self-documenting code is always
better.
