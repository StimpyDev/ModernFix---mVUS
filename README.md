# ModernFix-mVUS
ModernFix-mVUS is a fork of ModernFix that will release Modernfix versions for any version that is not supported by the official mod. When the official mod updates to a specific minecraft version this fork will skip releasing that version.

ModernFix-mVUS will not release any more updates for the **NeoForge** version of the mod for 1.21.11 and 26.1 as ModernFix has official repos for them on their Github.

## Downloads:
- https://modrinth.com/mod/modernfix-mvus
- https://www.curseforge.com/minecraft/mc-mods/modernfix-mvus

# Current state?
### Fabric is the only supported platform for 1.21.11 and future releases as the official ModernFix mod has completely dropped fabric support for the time being and will only release NeoForge jars for 1.21.11+.
